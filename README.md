# حصتي - تطبيق أندرويد

## بناء ملف APK عبر GitHub (بدون تثبيت برامج)

1. أنشئ حسابًا مجانيًا في github.com، ثم اضغط New repository واكتب أي اسم (مثل hissati) واتركه Public أو Private، ثم Create repository.
2. في صفحة المستودع اضغط "uploading an existing file".
3. فك ضغط الملف، ثم اسحب كل محتويات المجلد (package.json و capacitor.config.json و .gitignore و مجلد www ومجلد .github) إلى الصفحة، واضغط Commit changes.
4. افتح تبويب Actions. إن لم يظهر فيه "Build APK"، فمجلد .github لم يُرفع: اضغط Add file ثم Create new file، واكتب في خانة الاسم .github/workflows/build-apk.yml والصق محتوى الملف، ثم Commit.
5. انتظر نحو 5 إلى 8 دقائق حتى تظهر علامة صح خضراء بجانب Build APK.
6. افتح التشغيلة، ومن أسفل الصفحة (Artifacts) نزّل hissati-apk. سيكون ملفًا مضغوطًا فيه app-debug.apk.
7. انقله إلى الجوال وافتحه. اسمح بالتثبيت من هذا المصدر عندما يطلب الجوال.

## بعد التثبيت
- عند أول فتح اسمح بالإشعارات.
- اضغط "جرّب التنبيه" للتأكد.
- يُفضَّل استثناء التطبيق من توفير البطارية في إعدادات الجوال حتى لا يؤخر النظام التنبيهات.
- الحسابات والحصص تُحفظ على الجوال نفسه فقط.
